### Changed

- Requires `@dialecte/core` 0.12.1 (pinned exactly, was 0.12.0): a first value lookup after import builds its index in the call, and a subtree read goes by levels. `collectFromTree` no longer passes its `depth: Infinity` stopgap to `getTree`: a subtree below the document root is still read by levels, with no whole-document read.
