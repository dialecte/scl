### Changed

- **Breaking:** requires `@dialecte/core` 0.15.0 (pinned exactly, was 0.14.0). An app that reads through the engine directly gets its changes: `findAncestors` and `findAncestorsOfEach` walk through a `Private` and leave it out of the result (pass `unwrap: []` for every stored ancestor); every store keeps one version per document (`Store.readVersion`, the `version` a commit answers and an undo's or a redo's `HistoryStep` carries); a failed operation no longer leaves a progress bar behind (`doc.prepare` clears it on a throw); a copy of the library at another version no longer shares its storage kinds; and the SQLite engine and hub protocols moved (9 and 13), so tabs still running an older core are refused: close them before opening a project. scl's own answers are unchanged.
