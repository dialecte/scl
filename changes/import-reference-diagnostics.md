### Added

- **Import: a reference holding a uuid whose path cannot be written is reported** (`unwritten-reference-path`, a `warning` on the reference's path attribute). The import kept such a reference as read without a word; it now says why in `meta.reason`: `uuid-unresolved` (the uuid names no element of the file, an element of another file), `wrong-target` (an element the reference cannot point at, or one with no path of its own, an input without `intAddr`), `out-of-scope` (a behaviour variable naming an element out of its behaviour's reach) or `data-missing` (a behaviour variable naming its own behaviour's element with no data object). A reference holding a path beside such a uuid keeps its path, the diagnostic giving it in `meta.pathValue`. Types `UnwrittenReferencePathDiagnostic`, `UnwrittenReferencePathReason`.
