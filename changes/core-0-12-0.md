### Changed

- **Breaking**: requires `@dialecte/core` 0.12.0 (pinned exactly, was 0.11.0). Its breaks reach an SCL project as they reach any core project:
  - an exported SCL file declares every namespace on the `SCL` root, before the root's attributes (`<SCL xmlns="..." xmlns:eIEC61850-6-100="..." release="5" ...>`, where the 6-100 declaration came after `version`), and a declaration no record uses is no longer written; names and values are unchanged;
  - import stores no `xmlns` / `xmlns:*` attribute, so `getAttributes(ref, { fullObject: true })` lists none, and a transaction writing one is refused with `NAMESPACE_DECLARATION_NOT_ALLOWED`; `xsi:type` and QName values are stored resolved;
  - every commit, undo and redo message of the project channel carries its `changes` and a `changeId`; a store called directly takes `commit({ writeId })` and `undo` / `redo({ documentId, changeId })`;
  - projects stored by an earlier core are not migrated: export them with that version and import the file again.
