### Changed

- **Breaking:** requires `@dialecte/core` 0.14.0 (pinned exactly, was 0.12.1). An app that reads through the engine directly gets its changes: `getTree`'s `depth` counts the levels the caller sees (a hoisted transparent element no longer uses one up), a transaction's cached reads drop what another view's commit, an undo or a reimport changed, and a copy of the library at another version no longer shares its storage kinds. Imports of types make fewer store reads (a tag looked up often is read once per transaction).
