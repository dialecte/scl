### Changed

- **Breaking:** requires `@dialecte/core` 0.17.0 (pinned exactly, was 0.15.0). An app that reads through the engine directly gets its changes: a transparent element (`Private`) is walked through, hoisted or looked into only in its own namespace (`findAncestors`, `getTree`, `getSnapshot`, `getChild`, `getChildren`, `ensureChild`); a document created empty holds on its root the attributes its definition marks required and fixed; `tx.progress.runInPlan({ plan, run })` runs a step in a plan that always closes; `ProgressReporter` requires `runInPlan` and `SaveTarget` requires `discard` (a wrapper or a test fake adds them); and a copy of the library at another version no longer shares its storage kinds (storage kinds 18). scl's own answers are unchanged.
